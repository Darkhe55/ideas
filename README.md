# 深入创想（Ideas）

记录一些想法、论证过程与最终方案。以文档为主，必要的关键代码随文档内嵌。

## 目录结构

```
.
├── README.md
└── docs/
    ├── 简略说明版/    一句话 + 核心结构，30 秒看懂
    ├── 扩展中途版/    推导、备选方案、实验计划，随时修改的工作稿
    └── 最终版/        结论稳定、可直接照着实现的完整方案
```

## 三种文档

| 类型 | 回答的问题 | 读者 | 稳定性 |
| --- | --- | --- | --- |
| 简略说明版 | 这个想法是什么？值不值得展开？ | 任何人 | 一句话 + 结构图 + 指标 |
| 扩展中途版 | 为什么这样设计？还有哪些备选？ | 作者自己 | 工作稿，随时改，允许不完整 |
| 最终版 | 具体怎么做？边界在哪？ | 实现者 | 结论稳定，改动需记录理由 |

同一个想法在三个文件夹下使用**相同文件名**，文档头部互相链接。想法从「简略」开始，想清楚了升到「扩展」，结论稳定后沉淀为「最终」。

## 写作约定

- 每篇文档头部写明状态、最后更新日期，并链接同一想法的另外两个版本。
- 关键代码用 PyTorch 伪代码，追求「能看懂、能照着写」，不追求可直接运行。
- 用相对路径互链；中文为主，术语首次出现时附英文。
- 新的想法新建一份「简略说明版」，不要一上来就写最终版。

## 安全

本仓库为**公开仓库**，不提交任何密钥、令牌、账号密码、个人隐私信息与私有数据。`.gitignore` 已排除常见敏感文件；提交前请自查：

```bash
git status
git diff --cached
```
