# 深入创想（Ideas）

记录一些想法、论证过程与最终方案。以文档为主，必要的关键代码随文档内嵌。

## 目录结构

```
.
├── README.md
└── docs/
    ├── 简略说明版/    草稿：不超过 2 页
    ├── 扩展中途版/    扩充中：超过 2 页、不足 15 页
    └── 最终版/        成稿：超过 15 页
```

三个文件夹是**同一份文档的三个阶段**，不是三份文档。

## 收纳规则

- **一个想法只有一份文档**，同一时刻只存在于三个文件夹中的某一个，不并行、不重复收纳。
- 草稿（不超过 2 页）放在简略说明版；扩充超过 2 页后移到扩展中途版；继续续写超过 15 页后移到最终版。
- 迁移用 `git mv` 移动文件，文件名保持不变；早期阶段由 git 历史保留，不在工作区留副本。
- 文档头部标注当前「阶段」，迁移时同步更新。

## 写作约定

- 关键代码用 PyTorch 伪代码，追求「能看懂、能照着写」，不追求可直接运行。
- 用相对路径互链；中文为主，术语首次出现时附英文。
- 新的想法从简略说明版开始写，随内容增长逐级迁移。

## 安全

本仓库为**公开仓库**，不提交任何密钥、令牌、账号密码、个人隐私信息与私有数据。`.gitignore` 已排除常见敏感文件；提交前请自查：

```bash
git status
git diff --cached
```

## 同步

