# 快速预测框架（最终版）

> 状态：**稳定 v1.0** · 最后更新：2026-11-26
> 关联：[简略说明版](../简略说明版/快速预测框架.md) · [扩展中途版](../扩展中途版/快速预测框架.md)

## 0. 术语

| 记号 | 含义 |
| --- | --- |
| $\mathcal{V}$ | 全词表，$N = |\mathcal{V}|$，通常 $10^4 \sim 10^5$ |
| $x$ | 输入句子，建模为**词集**（无序，只记存在性） |
| $y$ | 输出回答，有序词序列 |
| $C$ | 压缩词表，$C \subseteq \mathcal{V}$，$|C| = k \ll N$ |
| $T(y)$ | 回答实际用到的词集合 |
| 覆盖率 | $T(y)$ 中落在 $C$ 内的比例 |
| 闭包 $\mathcal{G}$ | 固定保留词集合（标点、EOS 等） |

## 1. 摘要

标准语言模型在每一步都对全词表 $\mathcal{V}$ 做 softmax 并搜索，计算与搜索成本都随 $|\mathcal{V}|$ 线性增长。但真实回答只会用到几十个词。**快速预测框架**（Fast Prediction Framework，FPF）把「预测下一个词」显式拆成两个模块：

1. **词表分布预测**：输入无序词集，输出全词表的存在性概率，取压缩词表 $C$；
2. **词串生成**：只在 $C$ 内部做自回归组句，输出每个词都必须来自 $C$。

分解形式为 $p(y \mid x) = p(C \mid x)\, p(y \mid x, C)$。当 $C$ 由 $x$ 确定性给出、且 $T(y) \subseteq C$ 时，该分解是**精确的**——质量损失只来自覆盖率不足与模块二自身的建模误差，而不是一个有损的变分近似。

## 2. 问题定义

### 2.1 标准目标

$$
p(y \mid x) = \prod_{t=1}^{L} p(y_t \mid x, y_{<t}), \qquad y_t \in \mathcal{V}
$$

每一步需要：

1. 输出层把 $d$ 维隐状态映射到 $N$ 个 logits（$O(N d)$）；
2. 在 $N$ 个候选上做 softmax 与采样/比较；
3. 集束搜索时每步比较 $B \cdot N$ 个候选。

### 2.2 成本结构

| 项 | 标准 LM | 本框架 |
| --- | --- | --- |
| 输出层计算 | $O(L \cdot N \cdot d)$ | $O(N \cdot d) + O(L \cdot k \cdot d)$ |
| 输出 logits 显存 | $O(L \cdot N)$ | $O(N) + O(L \cdot k)$ |
| 每步搜索比较 | $O(B \cdot N)$ | $O(B \cdot k)$ |

以 $N = 10^5$、$k = 512$、$L = 32$、$d = 256$ 估算，输出层乘加次数从约 $8.2 \times 10^8$ 降到约 $3.0 \times 10^7$，约 **27 倍**。$k$ 取 256 时约 30 倍。

### 2.3 关键观察

回答的支撑集 $T(y)$ 很小，且主要由输入决定：

- 对话中，回答用词大多来自输入已出现的词（copy 通道）；
- 改写/摘要中，内容词由输入的语义决定；
- 功能词与标点几乎固定（闭包通道）。

因此“哪些词可能出现”可以**一次算完**，而“怎么排”才是真正的语言建模难题。

## 3. 形式化

### 3.1 分解

$$
p(y \mid x) = p(C \mid x) \cdot p(y \mid x, C)
$$

- $C = \operatorname{TopK}_k\big(\sigma(f_\theta(x))\big) \cup \mathcal{G}$，即 $C$ 是 $x$ 的确定性函数 $C(x)$；
- 模块二建模 $q_\phi(y \mid x, C) \approx p(y \mid x, C)$。

### 3.2 精确性条件

因为 $C(x)$ 是 $x$ 的函数，条件化不引入新信息：

$$
p(y \mid x, C(x)) = p(y \mid x)
$$

对任意满足 $T(y) \subseteq C(x)$ 的 $y$ 成立。因此：

> **框架的误差 = 覆盖率不足导致的不可表达误差 + 模块二的建模误差。**

没有额外的信息瓶颈损失。这也是它相比“先粗粒度分类再由小模型细化”等近似方案的优势。

### 3.3 目标函数

$$
\mathcal{L} = \mathcal{L}_{\text{cov}} + \lambda\, \mathcal{L}_{\text{gen}}
$$

$$
\mathcal{L}_{\text{cov}} = -\frac{1}{N}\sum_{v \in \mathcal{V}} w_v\Big[z_v \log p_v + (1-z_v)\log(1-p_v)\Big],\quad z_v = \mathbb{1}[v \in T(y)]
$$

$$
\mathcal{L}_{\text{gen}} = -\sum_{t=1}^{L} \log q_\phi(y_t \mid x, y_{<t}, C)
$$

其中 $w_v = \alpha$（正例）或 $1$（负例）。两模块可分别训练（$\lambda$ 阶段化），也可联合微调。

## 4. 模块一：词表分布预测

### 4.1 接口

```
输入  X: 词 id 集合（无序、去重），并附 mask
输出  s: R^N，p_v = sigmoid(s_v)
选词  C = TopK_k(p) ∪ G ∪ (X ∩ V)
```

设计约束：

- **置换不变**：输入顺序任意打乱，输出不变；
- **多标签**：每个词独立判断存在性，不是互斥 softmax；
- **一次前向**：整句只跑一次，不逐词调用。

### 4.2 结构

```
X（词集）
  │  Embedding（共享词表）
  ▼
Transformer × L1（无位置编码，置换等变）
  │  掩码均值池化（置换不变）
  ▼
h ∈ R^d
  │  Linear(d, N)
  ▼
p ∈ [0,1]^N
```

不加位置编码是刻意的：自注意力对输入置换等变，池化后得到与词序无关的句子表示，正好符合“只记词存在性”的约定。若输入很长（上千词），可改为局部窗口注意力或对输入做词频截断。

### 4.3 训练

- 目标集合：$z_v = \mathbb{1}[v \in T(y)]$，回答中重复词只算一次；
- 正负样本极不均衡（正例占比约 $L/N \approx 0.03\%$），必须加权或使用 focal loss；
- 难负例：对与输入高度相关但未出现在回答中的词（如同义候选、同主题词）加大惩罚；
- 选 checkpoint：以 Recall@$k$ 与整句覆盖率为准，而不是 BCE 值。

### 4.4 候选词表构造

$$
C = \operatorname{TopK}_k(p) \cup \mathcal{G} \cup (X \cap \mathcal{V})
$$

- $\mathcal{G}$：标点、EOS、UNK、数字占位符；可选高频虚词；
- $X \cap \mathcal{V}$：输入中出现的词，提供 copy 通道，显著提升对话/改写场景覆盖率；
- 阈值补充（可选）：$p_v > \tau$ 的词也纳入，用少量速度换覆盖率；
- 批处理时按 batch 内最大 $|C|$ 补齐到 $k_{\max}$，配合 `cand_mask`。

### 4.5 关键代码

```python
import torch
import torch.nn as nn
import torch.nn.functional as F


class VocabularyDistributionPredictor(nn.Module):
    """模块一：词表分布预测。

    输入：无序词集 X（去重后的词 id 数组）
    输出：全词表 logits，p_v = sigmoid(logit_v)
    """

    def __init__(self, vocab_size: int, d_model: int = 256, n_layers: int = 2):
        super().__init__()
        self.emb = nn.Embedding(vocab_size, d_model, padding_idx=0)
        layer = nn.TransformerEncoderLayer(
            d_model, nhead=4, dim_feedforward=4 * d_model,
            batch_first=True, norm_first=True,
        )
        # 关键：不给输入加位置编码。自注意力置换等变，池化后置换不变。
        self.encoder = nn.TransformerEncoder(layer, n_layers)
        self.classifier = nn.Linear(d_model, vocab_size)

    def forward(self, x_ids: torch.Tensor, x_mask: torch.Tensor) -> torch.Tensor:
        # x_ids: [B, n]；x_mask: [B, n]，1 表示真实词
        h = self.encoder(self.emb(x_ids), src_key_padding_mask=~x_mask.bool())
        pooled = (h * x_mask.unsqueeze(-1)).sum(1) / x_mask.sum(1, keepdim=True)
        return self.classifier(pooled)          # [B, N]
```

```python
def coverage_loss(logits, y_ids, pad_id=0, pos_weight=8.0):
    """模块一损失：多标签 BCE，目标集合 = 回答词集合（重复词只算一次）。"""
    target = torch.zeros_like(logits).scatter_(1, y_ids, 1.0)
    target[y_ids == pad_id] = 0.0
    weight = torch.where(target > 0, pos_weight, 1.0)
    return F.binary_cross_entropy_with_logits(logits, target, weight=weight)
```

```python
@torch.no_grad()
def select_candidates(logits, k, closure, extra_ids=None, pad_id=0):
    """构造压缩词表：TopK ∪ 闭包 ∪ 输入词（copy）。返回变长候选列表。"""
    B, N = logits.shape
    k = min(k, N)
    top = logits.topk(k, dim=-1).indices.tolist()          # [B][k]
    out = []
    for b in range(B):
        cand = set(top[b]) | set(closure.tolist())
        if extra_ids is not None:
            cand |= {t for t in extra_ids[b].tolist() if t != pad_id}
        out.append(sorted(cand))
    return out                                             # [B][k_i]
```

> 实现说明：不同样本的 $|C|$ 不同，`collate` 时按 batch 内最大长度补齐，同时产出 `cand_ids` 与 `cand_mask`。`extra_ids` 为补齐后的输入词 id（含输入去重集）。

### 4.6 指标

- **Recall@k**：$\mathbb{E}\big[|T(y) \cap C| / |T(y)|\big]$，token 级；
- **FullCoverageRate**：$\mathbb{P}[T(y) \subseteq C]$，整句全覆盖比例，决定端到端上限；
- 覆盖率随 $k$ 的曲线，以及与 $k$ 造成的加速比之间的权衡。

## 5. 模块二：词串生成

### 5.1 接口

```
输入  x: 输入句子（有序，供语序消歧）
      C: 压缩词表 + cand_mask
输出  y = (y_1..y_L)，每个 y_t ∈ C，不要求用完 C
```

> 为什么还要输入 $x$：$C$ 是无序词集，仅凭它无法唯一确定回答（“A 打 B”与“B 打 A”词集相同）。模块二读取有序输入以消歧；$C$ 只作硬约束，不做唯一信息源。

### 5.2 结构

```
x（有序） → 小型编码器 → mem
y_<t      → Decoder（交叉注意力 mem）
                │  h_t
                ▼
     logits = h_t · E^T   （共享词嵌入）
                │  gather 到 C 的候选下标
                ▼
          softmax over k → y_t
```

输出层不再投影到 $N$，而是从共享嵌入矩阵中 gather 出 $C$ 对应的行，softmax 只在 $k$ 个候选上做。批处理时用 `cand_mask` 把 pad 位置置为 $-\infty$。

### 5.3 约束解码

$$
q(y_t = v \mid \cdot) = \operatorname{softmax}_{v \in C}\big(h_t^\top e_v\big)
$$

- 贪心：每步取 $C$ 内得分最高者；
- 集束：每步保留 $B$ 条前缀，候选扩展集为 $C$，比较量 $O(Bk)$；
- EOS 必须在 $C$ 中（放入闭包 $\mathcal{G}$）；
- 输出长度上限 $L_{\max}$ 与重复惩罚同常规解码。

### 5.4 关键代码

```python
class WordStringGenerator(nn.Module):
    """模块二：词串生成。

    条件：有序输入 x 的表示 mem + 压缩词表 C。
    输出：只能落在 C 上的词串；softmax 维度 = |C| 而非 |V|。
    """

    def __init__(self, vocab_size: int, d_model: int = 256, n_layers: int = 4):
        super().__init__()
        self.emb = nn.Embedding(vocab_size, d_model, padding_idx=0)
        layer = nn.TransformerDecoderLayer(
            d_model, nhead=4, dim_feedforward=4 * d_model,
            batch_first=True, norm_first=True,
        )
        self.decoder = nn.TransformerDecoder(layer, n_layers)

    def forward(self, y_in, mem, cand_ids, cand_mask=None):
        # y_in: [B, L]；mem: [B, n, d]；cand_ids: [B, k]；cand_mask: [B, k]
        h = self.decoder(self.emb(y_in), mem)                 # [B, L, d]
        logits = h @ self.emb.weight.T                        # [B, L, N]，共享嵌入
        logits = logits.gather(2, cand_ids.unsqueeze(1).expand(-1, h.size(1), -1))
        if cand_mask is not None:                             # pad 候选置 -inf
            logits = logits.masked_fill(~cand_mask.bool().unsqueeze(1), float("-inf"))
        return logits                                         # [B, L, k]
```

```python
@torch.no_grad()
def constrained_decode(model, mem, cand_ids, cand_mask, bos_id, eos_id, max_len=64):
    """约束解码：每一步只在候选词表 C 内搜索。"""
    cand = cand_ids[0].tolist()
    ys = torch.tensor([[bos_id]])
    for _ in range(max_len):
        logits = model(ys, mem, cand_ids, cand_mask)[0, -1]   # [k]
        nxt = int(cand[int(logits.argmax())])
        ys = torch.cat([ys, torch.tensor([[nxt]])], dim=1)
        if nxt == eos_id:
            break
    return ys
```

> 集束搜索接口相同，仅把“取 argmax”换成“维护 $B$ 条得分最高的前缀”。

### 5.5 训练要点

- **目标**：teacher-forcing 交叉熵，只在 $C$ 上归一化；
- **候选噪声**：训练时对 gold 集合随机丢弃 10%～20%、加入少量干扰词，模拟模块一的漏词与多词；
- **两段式可选变体**：先由选择头预测子集 $S \subseteq C$（sigmoid 多标签），再由排序解码器排 $S$。直接自回归已能隐式完成“不必用全词”，两段式仅在长答案场景下作为备选；
- **联合微调**：对 $\operatorname{TopK}$ 使用 straight-through / Gumbel-softmax 估计器，让模块二的序列损失回传到模块一。

### 5.6 指标

- 端到端：BLEU / ROUGE / 任务准确率，与同参数量全词表基线对比；
- 受限困惑度：只在 $C$ 上计算，衡量模块二自身拟合；
- 速度：每句延迟、tokens/s、显存峰值。

## 6. 训练流程

```
阶段 0  数据构造
        x → 去重词集；y → 词序列；统计 T(y) 大小分布
阶段 1  模块一
        多标签 BCE，正样本加权；按 Recall@k / 覆盖率选模型
阶段 2  模块二（gold C）
        交叉熵 + 候选噪声；此阶段得到质量上限
阶段 3  模块二（预测 C）
        冻结模块一，用其输出的 C 继续训练（自蒸馏）
阶段 4  可选联合微调
        straight-through top-k + 序列损失；小学习率
```

顺序训练的理由：模块二若一开始就面对模块一的预测集合，会因为随机漏词学到“补偿策略”，掩盖模块一的覆盖率问题；先 gold 后预测，便于分别定位两类误差。

## 7. 推理与复杂度

```
输入 x
  │ 模块一（一次前向）
  ▼
s ∈ R^N → C（TopK + 闭包 + copy）
  │
  ▼
模块二（自回归，词表 = C）
  ▼
回答 y
```

- 模块一每句一次 $O(N d)$ 输出层；
- 模块二每步 $O(k d)$；
- 若 $L$ 较大，收益随 $L$ 增长而更明显；
- 训练时模块二的候选打包与 mask 是主要工程复杂度。

## 8. 评估方案

### 8.1 数据

建议覆盖三种任务形态：
- 对话（如 DailyDialog）：copy 通道收益明显；
- 摘要（如 CNN/DailyMail、LCSTS）：内容词由输入决定；
- 问答（如 SQuAD）：答案词常出现在输入中。

### 8.2 基线

1. 同参数量、同数据量的标准 Transformer LM；
2. 标准 LM + 每步 top-$k$ 采样（区分“每步截断”与“整句压缩词表”）；
3. 自适应 softmax（对比另一条降低输出层成本的路线）。

### 8.3 指标

| 类别 | 指标 |
| --- | --- |
| 覆盖率 | Recall@k、FullCoverageRate、$k$-覆盖率曲线 |
| 质量 | BLEU / ROUGE / EM / 任务准确率 |
| 语言建模 | 受限困惑度 |
| 效率 | 延迟、吞吐、输出层 FLOPs、显存 |
| 消融 | $k$、闭包、copy、候选噪声、联合训练 |

### 8.4 关键实验

- 覆盖率-加速比曲线：找到 $k$ 的拐点；
- 与基线在“同等延迟”下的质量对比；
- 不同输入长度下模块一的开销占比。

## 9. 局限与风险

1. **覆盖率不是 100%**：数字、专名、罕见词容易漏在 $C$ 外；v1 靠阈值与 copy 通道缓解，报告覆盖率为主要风险指标。
2. **无序输入的语义损失**：模块一按集合建模，否定、指代、主宾关系等信息被丢弃；模块二读有序输入可部分弥补，但模块一本身的预测质量会受影响。
3. **$k$ 预算固定**：长答案、枚举型答案需要更大 $k$，固定 $k$ 会顾此失彼；可行方向是按预测长度自适应。
4. **功能词占用预算**：闭包与虚词几乎必然出现，挤占内容词名额。
5. **两模块误差叠加**：模块一漏词时模块二无法补救，联合训练只能缓解。
6. **模块二容量**：小词表解码器对长程结构（如嵌套从句）的建模能力有限。
7. **分词粒度**：按词还是按 BPE；中文无空格，词边界本身需要约定。

## 10. 相关工作

- **Copy / 指针生成网络**：允许生成时复制输入词，但输出层仍覆盖全词表；本框架把“可复制词”作为压缩词表的一部分。
- **自适应 softmax**：用分层结构降低输出层成本，但解码仍逐词、搜索空间不变；本框架同时缩小输出层与搜索空间。
- **kNN-LM / RETRO**：从外部记忆或语料检索信息，解决“知识从哪来”；本框架解决“候选集多大”。
- **约束解码**：模块二正是“给定词表约束的生成”，只是约束由模块一动态给出。
- **Set2Seq**：集合到序列的建模，与本框架共享“无序输入 → 有序输出”的形式。
- **投机解码**：小模型起草、大模型验证，加速逐词生成；与本框架正交，可叠加。
- **非自回归 / 扩散语言模型**：并行生成，难点在顺序与一致性；本框架保留自回归但压缩词表。
