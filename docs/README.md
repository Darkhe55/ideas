# 文档规范

[简体中文](README.md) | [English](en/README.md)

## 生命周期

每种语言一个想法只有**一份文档**，随内容增长在三个文件夹之间迁移：

| 阶段 | 文件夹 | 篇幅 | 内容侧重 |
| --- | --- | --- | --- |
| 草稿 | `docs/简略说明版/` | ≤ 2 页 | 问题、一句话方案、核心结构、关键指标、主要风险 |
| 扩充中 | `docs/扩展中途版/` | > 2 页，≤ 15 页 | 推导、备选方案、伪代码、实验计划、待定问题 |
| 成稿 | `docs/最终版/` | > 15 页 | 形式化、接口、关键代码、评估方案、局限、相关工作、路线图 |

规则：

1. **每种语言只留一份**：同一想法在同一语言下任一时刻只有一份同名文档，三档不并行、不重复收纳；
2. **迁移即移动**：用 `git mv` 把文件从旧文件夹移到新文件夹，文件名不变；
3. **同步阶段字段**：迁移后更新文档头部的「阶段」；
4. **页数口径**：按 A4 打印或导出的实际页数估算（约 40 行/页，含代码与表格时每页行数更少）。

## 中英文镜像

英文文档放在 `docs/en/` 下，与中文保持相同的阶段层级：

| 中文 | English |
| --- | --- |
| `docs/简略说明版/` | `docs/en/brief/` |
| `docs/扩展中途版/` | `docs/en/extended/` |
| `docs/最终版/` | `docs/en/final/` |

- 英文文件使用英文文件名；
- 中英文档内容保持一致，修改时同步更新；
- 文档头部用「语言 / Language」一行互相链接。

## 迁移流程

```
简略说明版（草稿，≤ 2 页）
      │ 扩充超过 2 页
      ▼
扩展中途版（扩充中，2～15 页）
      │ 继续续写超过 15 页
      ▼
最终版（成稿，> 15 页）
```

早期阶段的内容由 git 历史保留，不在工作区留副本。

## 头部模板

```markdown
# 想法名称

> 阶段：简略说明版 / 扩展中途版 / 最终版 · 状态：草稿 / 建设中 / 稳定 vX.Y · 最后更新：YYYY-MM-DD
> 语言：[中文](path) · [English](path)

## ...
```

## 命名

- 文件名使用中文想法名，不加日期前缀；日期写在文档头部。
- 迁移时文件名保持不变。
- 英文版使用想法名的英文翻译作为文件名。
